## What's in this version

This is the cleaned-up final version. Compared to the working draft:
commented-out code has been removed, unused methods have been deleted,
restating comments have been trimmed down to only the ones explaining *why*
something is done, and extra blank lines have been collapsed. Functionality
is identical to the working draft — data loads from `inventory.csv` and
`services.csv` on startup and saves back out on exit or via the "Save Data"
menu option. Menu options 9 (Mark a Service Completed) and 10 (Restock a
Product) were added so `Service.markCompleted()` and `Product.restock()` —
present in the original skeleton but never reachable from any menu — are
actually usable; without option 9, a service could never be marked paid at all.
`Store.getInventory()`/`getServices()` were removed here since nothing in the
program ever called them.
